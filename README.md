# Ejemplo de uso de la librería *bpmn-js*

La librería javascript *bpmn-js* permite inctrustar en páginas web un editor/visualizador de diagramans realizados con notación BPMN. En este repositorio se encuentra el código fuente de una web de ejemplo en la que se puede ver su uso.

NOTA: para poder ejecutar este proyecto correctamente en un navegador, es necesario publicar el sitio web en un servidor web.
